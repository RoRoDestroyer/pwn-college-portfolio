[The Root]

Module: [Pondering Paths / Linux Luminarium]

Date: [8/28/2026]

[Objective]:

Using the Root directory, invoke the absolute path for the command `pwn` which is stored in the root.

[Key Concept]:

The Root is defined by `/` and invoking, say for instance, a program stored in root named `test`; executed by running `/test` that would be called invoking at the absolute path.

[Solution]:

Simply invoke the `pwn` command by the absolute root: `/pwn`

[# Relevant command(s) or code]:

`/` is the root. (If started with root, subsequent following path names would be called by absolute path)

[What I Learned]:

`/` is the root and running a path from the root is considered an absolute path.
