[Objective]:

Copy the /flag file into /tmp/hack-the-planet. Once done, run /challenge/check for the flag.

[Key Concept]:

The `cp` command copies a file to a location. Unlike the `mv` command, it keeps the original file in its original location. The `cp` command works with 2 arguments also: `cp arg1 arg2`. Argument 1 is the file you want to copy, while argument 2 is the location you want to copy that file into.

[Solution]:

Use the `cp` command to copy the flag file by writing out: `cp /flag /tmp/hack-the-planet`. Then run /challenge/check for the flag.

[# Relevant command(s) or code]:

The `cp` command copies files, the first argument passed is the file that is being copied, the second argument is the location to which you are copying your original file to.

[What I Learned]:

What the `cp` command is, the purpose of both its arguments and how to properly use it.
