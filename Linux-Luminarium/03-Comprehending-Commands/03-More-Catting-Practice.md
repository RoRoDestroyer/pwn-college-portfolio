[Objective]:

Read the `flag` file that is put in a random directory with the `cat` command without changing your directory.

[Key Concept]:

The `cat` command reads out files contents. The absolute path starts the file path at the root.

[Solution]:

Upon starting the challenge the terminal will notify the directory our file is located in. In this case: `You can find it in the file /usr/include/drm/flag` To cat this file write out `cat /usr/include/drm/flag` to receive the contents of the flag file via its absolute path.

[# Relevant command(s) or code]:

The `cat` command reads out files and or multiple files. Argument for file can be either relative or absolute.

[What I Learned]:

Once again reinforcement of using the `cat` command and reinforcement of absolute paths.
