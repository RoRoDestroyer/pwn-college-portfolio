Module: [Comprehending Commands / Linux Luminarium]

Date: [9/09/2026]

[Objective]:

Read the `flag` file located in the home directory with the `cat` command.

[Key Concept]:

The `cat` command is used to read out files, it concatenates multiple files if multiple arguments are provided. If no argument is provided it will repeat back whatever you input into the terminal. Once in that mode you must exit with `Ctrl+D` which signals the end of the file, or you can press `Ctrl+C` which forcefully interrupts the terminal. (Both of those commands are external knowledge not learned in this challenge)

[Solution]:

Simply write out `cat flag` to receive the contents of the flag file.

[# Relevant command(s) or code]:

The `cat` command reads out files and or multiple files. 

[What I Learned]:

The purpose of the `cat` command, how the `cat` command can read out multiple files rather than just one, and ultimately be used to read out what you type in as input into the terminal.
