[Objective]:

Move the /flag file into /tmp/hack-the-planet. You must use the MV command, no other way. Once done, run /challenge/check for the flag.

[Key Concept]:

The `mv` command moves files. The way the mv command works is it has 2 arguments: `mv arg1 arg2`. Argument 1 is the file that you want to move, and argument 2 is the location to where you are moving your file. For example: `mv test /example` would move the file `test` into the directory `/example`.

[Solution]:

Use the `mv` command to move the flag file by writing out: `mv /flag /tmp/hack-the-planet`. Then run /challenge/check for the flag.

[# Relevant command(s) or code]:

The `mv` command moves files, the first argument passed is the file that is being moved, the second argument is the location to which you are moving to.
