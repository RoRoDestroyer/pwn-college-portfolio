[Catting Absolute Paths]

Module: [Comprehending Commands / Linux Luminarium]

Date: [9/18/2026]

[Objective]:

Read the `flag` file located in the home directory with the `cat` command but this time by using the absolute path for `flag`.

[Key Concept]:

The `cat` command also allows for files to be called by the absolute path rather than just relative. Reinforcement of relative paths (file located in your current working directory) and absolute paths (file path starting from root: `/`).

[Solution]:

Simply write out `cat /flag` to receive the contents of the flag file via its absolute path.

[# Relevant command(s) or code]:

The `cat` command reads out files and or multiple files. 

[What I Learned]:

Reinforcement of using `cat` command and reinforcement of difference between relative and absolute paths.
