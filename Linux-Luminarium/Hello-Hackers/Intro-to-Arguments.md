[Intro to Arguments]

Module: [Hello Hackers / Linux Luminarium]

Date: [8/27/2026]

[Objective]:

Write your first command followed by an argument. In this case write the command "hello" followed with the argument "hackers"

[Key Concept]:

Arguments are additional data passed to commands. The first word is a command and the following word(s) are deemed arguments.

[Solution]:

Simply invoke the "hello" command followed by hackers in the same line, in the Linux terminal.

[# Relevant command(s) or code]:

Albeit not used for the challenge "echo" command echos the arguments provided. For example `echo Learning` will print "Learning" in the Linux terminal.

[What I Learned]:

The Linux shell parses our input into a command and its arguments. A command is the first word while the following words are the arguments to the command. The echo command is a great example of a command followed by arguments as the command is echo while the following words are the arguments.
